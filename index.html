Built for the daily loop.

Everything a team opens the app for, ready the moment it appears.

Zero-flicker loading

State is pre-fetched in the ViewModel, so screens appear complete with no layout shift and no duplicate Firestore reads.

Multi-team workspace

Switch teams from a selection sheet, or pick “All teams”. Every screen follows along reactively.

Smart daily brief

SummarizeDayCard pulls active tasks, upcoming deadlines and notices into one glance.

Live GitHub activity

GitHubLiveCard shows contribution stats, streaks and repository counts, fetched with coroutine-safe networking.

Push notifications

A custom FirebaseMessagingService delivers alerts to the system tray even when the app is closed.

Whitelisted access

Sign in with Firebase, then pass a check against whitelisted_users before entering a workspace.
